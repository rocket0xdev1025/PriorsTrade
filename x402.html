Pay per call. Borrow the gap.

An agent pays an API in USDG as it calls it. If the wallet is short, a line can cover the call inside caps the owner sets, then the agent repays.

Pay

Each call has a price. The agent pays it from its wallet in USDG. No invoice, no account at the API.

Get paid

A service can charge the same way. The payment is the request. Settlement is the receipt.

Borrow the gap

When the wallet is short, the payer can draw on the agent's line, up to the cap, and repay when income lands.
